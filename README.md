# Python

Try/except: Tratamento de exceção

- Cláusulas adicionais:
'else' = executar uma ação a partir do sucesso do try 
'finally' = finalizar o try independentemente de seu resultado

- Tipos de exceção (except):
ZeroDivisionError
ValueError
KeyError

Como mudar o default do fim do print

- print('mensagem', end = ' '); escreva o que quiser e aparecerá seguido do print da Main
- Útil para executar uma procedure que imprime na tela,  mas você deseja que o print da procedure apareça em sequencia do print da Main
